# Third-Party Code

The scene encoder, base motion decoder, transformer layers, data utilities,
evaluation utilities, and CUDA operators contain code adapted from the
[Motion Transformer](https://github.com/sshaoshuai/MTR) project. Those parts
remain available under the Apache License 2.0 included in this repository.

Attribution is consolidated in this file so that source headers describe each
module's responsibility rather than its development history.
